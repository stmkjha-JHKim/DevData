OraPulse Backup

Oracle Data Pump 기반
중앙 백업 관리

  • Data Pump로 Export / Import 백업
  • 정책 기반 자동 스케줄링
  • 여러 DB의 백업 현황을 한 곳에서 관리
  • DB 접속 정보는 이 서버에만 암호화 저장

백업 대상 DB 등록

접속 정보를 입력해 새 DB를 등록하거나, 이미 등록된 DB를 선택하세요.

* DB 접속 정보(비밀번호 포함)는 이 서버의 로컬 데이터에 AES-256-GCM으로 암호화되어 저장되며, 등록된 각 DB의 백업 정책·이력이 대시보드에서 함께 관리됩니다.
* Data Pump Export/Import를 실행하려면 이 계정에 EXP_FULL_DATABASE / IMP_FULL_DATABASE 권한과 Directory Object 사용 권한이 필요합니다.
